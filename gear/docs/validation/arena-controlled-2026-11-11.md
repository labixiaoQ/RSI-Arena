# MoneCraft 最小闭环验收记录 · 2026-11-11

受控改进器与真实 MoneCraft 裁判的三代实验已完成。这里验证的是继承、评测与验收机制，不是大模型自主 RSI 能力。正式隐藏测试尚未实现。

候选 E 始终与 E0 相同。I0 的一步后续学习产生静止策略，I1 产生记忆地图的采矿策略，I2 产生上游 SDK 样例策略。三者是预先准备的测试策略；I2 在这组开发任务上更弱，因此没有被继承。日志中的实际提案执行者为 I0、I1、I1，符合 Gear 导出结果，而不是始终调用初始 I0。

最终账本：19 次受控 agent 调用、0 次模型请求、0 token、8 个学习评测、32 局。32 局均由原版裁判正常完成 1000 回合；没有不明调用。每个学习轨迹均为一层后续评测。恢复时把改进器与游戏执行接口设为“调用即报错”，仍能返回相同结果，且没有新增消耗。

50 项测试通过：14 项 Arena 闭环/预算/恢复测试，3 项不联网的模型接口测试，33 项 Gear 原有控制器/目标测试。类型检查、依赖边界、契约、修改文件格式与安装后公共接口检查通过。真实运行环境另通过裁判平局与编译访问隔离两项检查。

首次受控采矿基线缺少地图记忆，产生来回走的行为。该校准实验被停止，其结果保留在 `arena-runs/fixture-20261111`：两代均拒绝，已确认 17 局，另有中断中的 1 局保留预留，共计费 18 局，没有将不明执行返还为可用预算。修正后的独立实验位于 `arena-runs/fixture-memory-20261111`。

本受控实验没有模型请求。用户随后已授权真实 DeepSeek 试验，其 SDK 修复、预算合计和有效结果另见 [真实模型试验记录](arena-deepseek-2026-11-11.md)，不能与本受控实验混为模型自主 RSI 的证据。

运行环境为 Mac + Colima + Rosetta 的开发适配路径，包含专用 AppArmor 配置与 Bubblewrap 兼容层，不能作为 AAArena 原生参考环境的榜单结果。所有评分只来自两个开发 seed 和两个固定对手，没有统计显著性或泛化结论。
